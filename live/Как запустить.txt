Перрон-15 · Сайт смены

На ноутбуке
1. Запустите «Запустить.cmd» в папке сайта. Требуется Node.js 22 или новее.
2. Откройте http://127.0.0.1:8175. Оставьте окно сервера открытым.
3. Выберите «Диспетчер» и введите код из строки «Диспетчер» в окне сервера.
4. Для проверки двух ролей на одном компьютере откройте приватное окно браузера, выберите «Инженер» и введите один из инженерных кодов.

На Android по USB (для полной проверки на месте)
Подключите свой телефон к ноутбуку. Если используете Android Platform Tools и разрешили отладку по USB на этом телефоне, выполните на ноутбуке:
adb reverse tcp:8175 tcp:8175
Откройте http://localhost:8175 в Chrome на телефоне, войдите как инженер и нажмите «Включить GPS». Разрешите доступ к местоположению. Держите страницу открытой во время показа. После проверки отключите передачу и USB-отладку. Чтобы убрать перенаправление, выполните adb reverse --remove tcp:8175.

Для доступа с телефона по Wi-Fi требуется HTTPS с сертификатом, которому доверяет телефон. Сервер поддерживает переменные TLS_CERT и TLS_KEY для путей к PEM-сертификату и ключу, HOST для адреса прослушивания, PORT для порта. По умолчанию сайт слушает только этот компьютер.

Вызов
В кабинете диспетчера выберите зону, тип ВС, неисправность и приоритет. При необходимости введите бортовой номер. Нажмите «Зафиксировать вызов» и выберите его в очереди. Срочные вызовы показаны первыми. Карта и расчёт обновляются каждые три секунды. Для живой смены используется пеший маршрут по пешеходным и служебным дорогам конкурсного полигона ВДНХ. Время в пути рассчитывается при скорости 5 км/ч, к нему прибавляются две минуты подготовки. Сайт сравнивает двух участников одинакового профиля. При GPS-точке за пределами доступной сети, точности хуже 50 м или давности более минуты назначение недоступно. Сценарии Шереметьево с подбором по квалификации расположены по отдельной ссылке в кабинете диспетчера.

Диспетчер нажимает «Назначить». Инженер видит номер зоны и после выполнения нажимает «Завершить задание». Кнопка «Остановить передачу» снимает позицию инженера с карты. Координаты, задания и коды хранятся в памяти сервера до перезапуска. При новом запуске сохраните новые коды из окна сервера.
